# Generating Stable Diffusion 3 Images (for SPAI-style testing)

## ⚠️ Important caveat first

**The SPAI paper does not document a generation config for their SD3 test images.** They did not generate these images themselves — they collected them from an existing online dataset. The only relevant line in the paper (Section 4.1) is:

> "we employ the online sources of [25, 43] to collect images generated by Flux and Stable Diffusion 3 (SD3) [20] respectively."

Reference [43] in the bibliography is listed as:
> LatentSpacer. "Civitai: Dataset with 6000+ flux.1 dev images," 2024.

That's a **Flux** dataset citation, not SD3 — so there's an apparent mismatch/ambiguity in the paper about exactly where the SD3 images came from. There is no seed list, prompt set, guidance scale, step count, sampler, or resolution setting documented anywhere in the paper or the [GitHub repo](https://github.com/mever-team/spai) for how those specific SD3 images were produced.

**What this means for you:** if your goal is to exactly reproduce the *same 1,000 SD3 images* used in Table 1, you can't do it by generating new ones — you need to download the authors' packaged copy of those exact images from the Drive link in `docs/data.md` (see the other reproduction file). Generating fresh SD3 images will give you *comparable, same-model* images, not the *identical* dataset.

Below is a reasonable, well-documented config for generating SD3 images yourself using standard/recommended settings — useful for testing SPAI's detector on fresh SD3 outputs, but not a reconstruction of the authors' original process.

---

## 1. Which SD3 checkpoint

Stability AI released several SD3 variants. As of when this paper was written (late 2024/early 2025), the relevant ones were:

- `stabilityai/stable-diffusion-3-medium` (2B params, the openly released one at the time)
- `stabilityai/stable-diffusion-3.5-large` / `-large-turbo` / `-medium` (released later, Oct 2024)

Since the paper cites plain "SD3" (not 3.5), the closest match is **Stable Diffusion 3 Medium**, available on HuggingFace:
https://huggingface.co/stabilityai/stable-diffusion-3-medium

(Requires accepting Stability AI's community license on HuggingFace.)

## 2. Recommended generation settings (Stability AI defaults, not SPAI-specific)

| Parameter | Value | Notes |
|---|---|---|
| Model | `stabilityai/stable-diffusion-3-medium-diffusers` | |
| Resolution | 1024×1024 | Matches paper's Table 6 average size for SD3 (~1.0 MP) |
| Guidance scale (CFG) | 7.0 | Stability AI's recommended default for SD3 Medium |
| Inference steps | 28 | Stability AI's recommended default |
| Sampler / scheduler | FlowMatchEulerDiscreteScheduler | Default scheduler shipped with the SD3 pipeline |
| Precision | fp16 or bf16 | For reasonable VRAM usage |
| Negative prompt | none required (SD3 doesn't need one, but can be used) | |

## 3. Minimal working example (Diffusers)

```bash
pip install diffusers transformers accelerate sentencepiece protobuf torch --upgrade
```

```python
import torch
from diffusers import StableDiffusion3Pipeline

pipe = StableDiffusion3Pipeline.from_pretrained(
    "stabilityai/stable-diffusion-3-medium-diffusers",
    torch_dtype=torch.float16
)
pipe = pipe.to("cuda")

image = pipe(
    prompt="a photorealistic portrait of an elderly fisherman mending nets at dawn",
    negative_prompt="",
    num_inference_steps=28,
    guidance_scale=7.0,
    height=1024,
    width=1024,
).images[0]

image.save("sd3_output.png")
```

## 4. Hardware requirements

- SD3 Medium: ~16-18GB VRAM at fp16 for the full pipeline (can be reduced with CPU offloading via `pipe.enable_model_cpu_offload()`)
- A100/L40/4090-class GPU recommended for reasonable generation speed

## 5. On prompts

The SPAI paper gives no indication of what prompts were used to generate the SD3 images in their test set — it's a topically diverse dataset (Table 6 lists 1,000 images averaging ~1.0 MP). If your goal is just to stress-test a detector (like SPAI) against SD3 output in general, prompt diversity matters more than matching any specific prompt list, since none exists publicly from this paper.

## 6. If you actually need the *exact* images from the paper

Use the pre-packaged download instead of generating new ones — see `docs/data.md` in the SPAI repo:
> "we further facilitate the downloading of Stable Diffusion 3, MidJourney v6.1, GigaGAN and Flux images by making them available [here](https://drive.google.com/file/d/1no5T89h97TZvAKNCHKt2PQfKZ1UDtbI4/view)"

This is the only way to get the literal same 1,000 SD3 images the 75.9% AUC score was computed on.
